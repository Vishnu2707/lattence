# Vulnerable agent fixture

This project is intentionally unsafe. It exists only for local Lattence tests
and demonstrations. Do not deploy it or connect it to real data, credentials,
tools, or services.

The source declares an agent with persistent memory and delegation, an
unclassified retrieval path, a destructive tool, a credentialed MCP server,
and classical public-key cryptography. The functions return fixture strings and
make no network calls.
