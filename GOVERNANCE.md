# Governance

Lattence has one maintainer today, listed in
[MAINTAINERS.md](MAINTAINERS.md). The maintainer makes final decisions on
scope, design, and what merges, informed by issue and pull request
discussion.

There is no formal steering committee or voting process yet. As the
contributor base grows, this file will describe how additional maintainers
are added and how decisions are made among them. Until then, open an issue
to propose a nontrivial change before sending a pull request, so the
direction can be agreed on before the work is done.
